# مخزون الفروع (GescomStock)

لوحة واحدة ترى فيها **مخزون كل الفروع**، وكل فرع يعمل ببرنامج Gescomm وبقاعدته المحلية (InterBase 7.5).

```
فرع A (Gescomm + InterBase) ── وكيل ──┐
فرع B (Gescomm + InterBase) ── وكيل ──┼── HTTPS صادر فقط ──► Laravel (هذا المستودع) + MySQL ──► لوحة البحث
فرع C (Gescomm + InterBase) ── وكيل ──┘
```

- **الوكيل** (`agent/`): سكريبت PowerShell على سيرفر كل فرع.
  - يقرأ `GC003` (الكود، التسمية، الكمية) **قراءة فقط**، ويرسلها كل 5 دقائق.
  - يجاوب على «تحديث الآن» خلال 10 ثوانٍ تقريباً.
  - لا يحتاج تثبيت أي برنامج، ولا يفتح أي منفذ في الفرع.
- **اللوحة:**
  - **البحث بالكود أو التسمية:** سطر واحد لكل منتج، مع مجموع الكميات وعدد الفروع.
  - **«معاينة»:** نافذة بكمية كل فرع، والكود والتسمية كما هما مكتوبان عند ذلك الفرع.
  - **«تحديث الآن»:** يقرأ الكمية من كل فرع في تلك اللحظة.
  - **صفحة «الفروع»:** الحالة، وآخر مزامنة، وأكواد التركيب، والتعطيل.
- **تمييز الفروع:**
  - عند التركيب يُعطى للوكيل **اسم الفرع** و**كود تركيب** صالح لمرة واحدة.
  - الـAPI يرجّع للوكيل **توكناً خاصاً به**.
  - المركز يعرف الفرع من هذا التوكن.

## التشغيل محلياً
```bash
composer install
cp .env.example .env && php artisan key:generate
php artisan migrate
php artisan user:create admin@local.test --name=Admin
php artisan serve
```

- **الاختبارات:** `php artisan test`
- **ربط وكيل محلي:**
  1. أنشئ كوداً: `php artisan agent:install-code`.
  2. في إعداد الوكيل: `"api_url": "http://127.0.0.1:8000/api"`. الـ`http` مقبول فقط لـ localhost.
